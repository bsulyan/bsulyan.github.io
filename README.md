# bsulyan.github.io

Personal site and technical notes by **Bastien Sulyan**, independent software developer in Strasbourg, France.

Live site: [https://bsulyan.github.io/](https://bsulyan.github.io/)

## Projects

- **[Sunasty](https://sunasty.com/)** — Client-side file tools (PDF, image, audio, video, QR, and developer utilities) running directly in the browser via Web Workers and WebAssembly.
- **[Ulysan](https://ulysan.fr/)** — Independent web studio in Strasbourg and offline mobile games ([Solitaire for Android](https://ulysan.fr/solitaire/)).
- **[Sunasty QR Scanner](https://github.com/bsulyan/sunasty-qr-scanner)** — Manifest V3 Chrome extension for local QR scanning and generation.
- **[Sunasty Color Picker](https://github.com/bsulyan/sunasty-color-picker)** — Manifest V3 Chrome extension for HEX, RGB, HSL, OKLCH conversion and WCAG 2.1 contrast calculation.
