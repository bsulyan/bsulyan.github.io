Bastien Sulyan

Independent software developer in Strasbourg, France

I design and build static web software, client-side file utilities, and offline mobile applications. My work focuses on running binary document, media, and image pipelines directly inside the browser using Web Workers, WebAssembly, and native Web APIs so user files do not have to pass through remote servers.

I run Ulysan, an independent web and software studio in Strasbourg, and build Sunasty, a collection of browser-side tools for PDF, image, audio, video, and developer workflows.

Technical Notes

Implementation notes and reference code drawn from building client-side document, image, color, and audio utilities.

  • Processing PDF Files in the Browser Without a Backend

    Working with PDF cross-reference tables, ArrayBuffer transfers to Web Workers, page merging, stream recompression, and inspecting /Info dictionaries and XMP packets locally.

  • Inspecting and Stripping EXIF, GPS, and C2PA Metadata in the Browser

    Parsing JPEG markers (APP1, APP11), reading TIFF IFD tags and JUMBF c2pa provenance boxes, and stripping metadata without full pixel recompression.

  • Decoding Small and Low-Contrast QR Codes on HTML5 Canvas

    Why single-pass jsQR scans fail on full-page screenshots, overlapping 3×3 spatial tiling, local thresholding, and RFC 6238 TOTP generation with SubtleCrypto.

  • sRGB, OKLCH, and WCAG 2.1 Contrast Calculations in Pure JavaScript

    Gamma linearization, Björn Ottosson's Oklab matrices, relative luminance ratios, and binary search over perceptual lightness L to meet WCAG AA/AAA targets while preserving hue.

  • Client-Side Audio Extraction and Podcast Cleanup in the Browser

    Demuxing MP4 containers to MP3 or WAV in WebAssembly, reading ID3v2 frames, stem separation constraints in memory, and local loudness normalization for spoken-word recordings.

Projects & Open-Source Tools

Sunasty — Browser-Side File Tools

Over 60 browser utilities that process files locally on the user's device: PDF tools (merge, compress, metadata, deskew), image tools (EXIF inspector, C2PA reader, compression), audio and video utilities, privacy checks, and developer tools. Architecture & integration guides are published on Read the Docs, audio pipeline notes on DEV Community, and the public listing on AlternativeTo.

Ulysan — Web Studio & Offline Mobile Games

Independent software studio based in Strasbourg building bespoke static web sites, custom business web applications, and ad-respectful offline mobile games such as Klondike Solitaire for Android.

Sunasty QR Scanner (Chrome, Firefox & Edge Extension, MIT)

Manifest V3 browser extension published on the Chrome Web Store, Firefox Add-ons (AMO) (FR), and Microsoft Edge Add-ons that scans QR codes from the active tab, images, or clipboard, decodes Wi-Fi and otpauth:// payloads locally, and generates SVG/PNG codes. Companion to the Sunasty Web QR Scanner and QR Generator, with its payload parser published on npm as sunasty-qr-payload (GitHub).

Sunasty Color Picker & sunasty-color-math (MIT)

Manifest V3 eyedropper and zero-dependency color conversion library (npm · PyPI · Crates.io · docs.rs · pkg.go.dev · Packagist · pub.dev / publisher · GitHub) supporting HEX, RGB, HSL, and OKLCH, with live WCAG 2.1 contrast checks and accessible shade suggestions. Companion to the Sunasty Web Color Picker and WCAG Contrast Checker.
