Independent software developer in Strasbourg, France

I design and build static web software, client-side file utilities, browser extensions, and offline mobile applications. My work focuses on running binary document, media, and image pipelines directly inside the browser using Web Workers, WebAssembly, and native Web APIs so user files do not have to pass through remote servers.

I run Ulysan, an independent web and software studio in Strasbourg, and build Sunasty, a suite of 233 browser-side tools across 32 languages for PDF, image, audio, video, privacy, date, calculator, and developer workflows.

Technical Notes

Implementation notes and reference code drawn from building client-side document, image, color, audio, network, and combinatorial utilities.

  • Whitelist HAR Sanitization in the Browser: Zero-Copy Redaction Without Secret Leaks

    Bounded structural JSON parsing, forensic location inventory, domain-filtered HAR 1.2 whitelist reconstruction, and timing-preserving waterfall exports (sunasty-har-sanitizer).

  • Swiss Tournament Tiebreakers and Binomial Cut Math in JavaScript

    Expected win-loss field convolution with draws, cross-seeded playoff bracket generation, and deterministic Monte-Carlo OMW%/OOMW%/Σr² tiebreaker odds (sunasty-tournament-math).

  • Pure JavaScript Code 128B/C, EAN-13, and ITF-14 Vector SVG Barcode Encoding

    Automatic numeric Subset C packing, Mod-10 and Mod-103 checksum calculation, run-length bar segment merging, and standalone SVG generation without DOM APIs (sunasty-code128-svg).

  • Processing PDF Files in the Browser Without a Backend

    Working with PDF cross-reference tables, ArrayBuffer transfers to Web Workers, page merging, stream recompression, and inspecting /Info dictionaries and XMP packets locally.

  • Inspecting and Stripping EXIF, GPS, and C2PA Metadata in the Browser

    Parsing JPEG markers (APP1, APP11), reading TIFF IFD tags and JUMBF c2pa provenance boxes, and stripping metadata without full pixel recompression.

  • Decoding Small and Low-Contrast QR Codes on HTML5 Canvas

    Why single-pass jsQR scans fail on full-page screenshots, overlapping 3×3 spatial tiling, local thresholding, and RFC 6238 TOTP generation with SubtleCrypto.

  • sRGB, OKLCH, and WCAG 2.1 Contrast Calculations in Pure JavaScript

    Gamma linearization, Björn Ottosson's Oklab matrices, relative luminance ratios, and binary search over perceptual lightness L to meet WCAG AA/AAA targets while preserving hue.

  • Client-Side Audio Extraction and Podcast Cleanup in the Browser

    Demuxing MP4 containers to MP3 or WAV in WebAssembly, reading ID3v2 frames, stem separation constraints in memory, and local loudness normalization for spoken-word recordings.
